#
#     ANTHROPIC_API_KEY=sk-ant-...
#     NVIDIA_API_KEY=nvapi-...
#
# An Anthropic key wins if both are present. LLM_PROVIDER overrides the
# guess and accepts: anthropic | nvidia | none.
#
# NVIDIA settings, all optional:
#     NVIDIA_MODEL       default nvidia/nemotron-3-super-120b-a12b
#     NVIDIA_BASE_URL    default https://integrate.api.nvidia.com/v1
#     NVIDIA_THINKING    set true to leave the model's reasoning on
#
# Without any key the agent runs unchanged: extraction is skipped and the
# explanation falls back to a deterministic summary built from the
# verified record. Nothing about the agent's correctness depends on a
# model — every extracted fact must quote its source verbatim, or it is
# discarded, whichever provider produced it.
